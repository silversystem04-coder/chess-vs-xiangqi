规则

同一张 9×10 的交叉点棋盘上两军对垒：下方是中国象棋·红方（先手），上方是国际象棋·钢蓝方。棋盘用国际象棋的深浅格美术风格，中间那条河叫乌拉尔河。各子只遵守自己棋种的走法，吃掉对方的「帅 / 王」即获胜。

中国象棋方（红）

  • 帅 九宫内一步直行；另有「飞将」：与自己同一条直线上（中间无子）若是对方的王，可以直接飞过去吃掉。这个特权只有红方有。
  • 仕 九宫内一步斜行。
  • 相 走「田」字，塞象眼不可行，且不能过河。
  • 马 走「日」字，蹩马腿不可行。
  • 车 直线任意格；炮 走法同车，但吃子必须隔一个棋子（炮架），且只能吃炮架后的第一个子。
  • 兵 只进不退；过河后可以横走，走法与吃法相同。本局两个边兵摆在 b4 / h4。

国际象棋方（钢蓝）

  • ♚ 王：周围一格。 ♛ 后：直线斜线任意格。
  • ♜ 车：直线任意格。 ♝ 象：斜线任意格。
  • ♞ 马：走「日」字，不蹩腿。
  • ♟ 兵：向前一格，首步可两格；只能斜吃；走到底线升变为后。
  • 斜着走的子不能跨河：后、象（以及王的那两步斜走）只能沿斜线走到岸边停住， 想过去必须单独走一格直走（比如象 e6→e5），过了河才能在对面继续斜着打。 车、后、兵的直线走法不受影响；中国象棋方没有斜着滑行的子，不受这条约束。
  • 本局不含王车易位与吃过路兵。
  • 本局布局：后排七子缩进一排（b10..h10 = 车 马 象 · 后 · 象 马 车），王站在王后正前方的 e9。兵墙压在王与双象前面（c9 / d9 / f9 / g9），所以「后」开局一步都走不了——和真棋一样被自己的兵锁住；双车所在这两条线（b9 / h9）特意留空，车不挡；e8 是王前哨兵。

胜负与简化约定

  • 为便于两种规则共存，不作「不可送将 / 不可自我将军」的限制：把帅或王走进对方火力网是允许的，只是会被吃掉。界面会在被攻击时亮出「将军！」提醒。
  • 同样地，被将军时并没有强制解将的义务——但主帅被吃就结束了。
  • 连续 50 回合（100 步）无吃子判和。
  • 棋盘用国际象棋的深浅格配色；中间那条「乌拉尔河」只是分界线，不限制任何走法。九宫对角线只约束红方的帅与仕。
  • 注意：黑王站在 e9，e 线是它的软肋——红方开局「炮 b3→e3」就能隔着自己的 e4 兵直接瞄准它，黑方必须应对；更要注意飞将：e 线上只要红兵让开、e8 哨兵又没了，红帅就能一口气飞上去吃王。反过来，红帅在九宫里只有 3 个相邻格，两侧被自己的仕堵着，只要黑方有子走到 d2 或 f2 就是闷宫杀。
  • 自定开局：点「摆棋」可以把棋子随便挪、加、删，摆好后「保存为初始棋盘」，之后每局都从这里开始；「导出 HTML」会把这个开局写进一个独立文件，双击就能玩这一版。
