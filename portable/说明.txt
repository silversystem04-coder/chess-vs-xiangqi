中西对弈 · 国际象棋 vs 中国象棋
================================

这是什么
--------
一个单文件网页游戏：一张 9×10 的棋盘上，下方是中国象棋（红方、先手），
上方是国际象棋（钢蓝方）。两军各子只按自己棋种的走法行动，
吃掉对方的「帅 / 王」就赢。

怎么玩
------
双击 chess-vs-xiangqi.html，用浏览器打开即可（Chrome / Edge / Firefox / Safari 都行，
Windows / Mac / Linux 都行，手机也能打开）。

不需要联网，不需要安装任何东西，没有任何外部文件依赖。
整个游戏就在这一个 58 KB 的文件里。

- 点自己的棋子 → 高亮落点 → 点落点落子
- 上一步有金色角标；被将军时主帅亮红光，面板出现「将军！」
- 右侧面板：双人对弈 / 电脑执国际 / 电脑执中国，棋力三档，棋盘尺寸四档
- 快捷键：N 新局、U 悔棋、Esc 取消选中

改开局（这是这一版的重点）
--------------------------
点面板上的「摆棋」：

1. 先在调色板里选一个棋子（红方：帅仕相马车炮兵；蓝方：王后车象马兵；✕ 是橡皮），
   再点棋盘放置
2. 不选子的时候，点一下自己的子、再点目标格，可以搬子；右键直接删除
3. 编辑器会实时统计「红 N 子（帅 x）· 蓝 M 子（王 y）」，
   必须有且只有一个帅、一个王，才能保存
4. 「保存为初始棋盘」：之后每次新局都从这个局面开始（存在本机浏览器里）
5. 「恢复默认开局」：一键还原
6. 「导出 HTML」：把当前局面写进一个新的 HTML 文件并下载

把自定义的那一版发给别人
------------------------
摆好 → 点「导出 HTML」→ 得到 chess-vs-xiangqi-custom.html。
这个文件已经把开局内嵌进去了，对方双击打开就是你这一版，不需要任何额外操作。

注意事项
--------
- 自定义开局存在浏览器的 localStorage 里：换电脑、换浏览器不会自动带过去，
  要用「导出 HTML」导出带走。
- 如果界面字体和截图不太一样，是那台机器缺楷体（KaiTi），不影响玩法和布局。
- 本游戏约定：不判「送将 / 自我将军」，被将军也可以不理——主帅被吃就结束；
  连续 50 回合（100 步）无吃子判和。

蓝方布局：后排七子缩进一排（车马象·后·象马车），兵墙在 c9/d9/f9/g9 把「后」锁死
（开局一步都走不了，和真棋一样），双车所在的 b9/h9 特意留空让车能走。

规则速查
--------
红方（中国象棋）  帅：九宫内一步直行，另有「飞将」——同列无阻挡时可直接吃蓝王（只有红方有）
                 仕：九宫内一步斜行    相：走田字、塞象眼、不过河
                 马：走日字、蹩马腿    车：直线任意格
                 炮：走同车，吃子必须隔一个炮架
                 兵：只进不退，过河后可横走

蓝方（国际象棋）  王：周围一格（没有飞将）   后：直线斜线任意格
                 【过河】后、象、王的斜走不能跨乌拉尔河：斜线停在岸边，
                 想过河要单独走一格直走（象 e6→e5），过了河才能继续斜着打
                 车：直线任意格             象：斜线任意格
                 马：走日字、不蹩腿
                 兵：直进一格、首步两格，只斜吃，到底线升后

不含王车易位与吃过路兵。
